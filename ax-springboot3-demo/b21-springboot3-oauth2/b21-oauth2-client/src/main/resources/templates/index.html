Spring Boot 3 OAuth2 演示系统

这是一个基于 Spring Authorization Server 的 OAuth2 企业级演示项目。
包含授权服务器、资源服务器和客户端三个模块，支持微服务架构和单体应用两种部署模式。

授权服务器

基于 Spring Authorization Server，支持授权码模式、客户端凭证模式、设备码模式和刷新令牌。

资源服务器

提供受OAuth2保护的REST API，支持JWT令牌验证和方法级权限控制。

客户端应用

集成OAuth2登录，管理访问令牌，调用受保护的资源API并展示数据。
