# Spring Boot 3 OAuth2 企业版需求与设计文档

## 1. 项目概述

### 1.1 项目背景
基于 Spring Boot 3 和 Spring Authorization Server 的 OAuth2 企业级演示项目，支持微服务架构和单体应用两种部署模式。

### 1.2 技术栈

| 技术 | 版本 | 说明 |
|------|------|------|
| Spring Boot | 3.5.8 | 核心框架 |
| Java | 21 | 开发语言 |
| MySQL | 8.0+ | 关系型数据库 |
| MyBatis-Plus | 3.5.6+ | ORM 框架 |
| Spring Security OAuth2 | 最新 | 安全认证 |
| Thymeleaf | 最新 | 模板引擎 |

### 1.3 架构模式

```
┌─────────────────────────────────────────────────────────────┐
│                    两种部署模式                                │
├─────────────────┬───────────────────────────────────────────┤
│   微服务架构     │             单体应用                        │
│                 │                                           │
│ ┌─────────────┐ │ ┌───────────────────────────────────────┐ │
│ │  Auth Server │ │ │  All-in-One: Auth + Resource + Client │ │

## 3. 数据库设计

### 3.1 数据库规范

#### 3.1.1 命名规范
- 表名: `sys_` 前缀 + 功能模块 + 实体名（如: `sys_user`）
- 字段名: 小写字母 + 下划线（如: `user_name`）
- 索引名: `idx_` + 表名 + 字段名（如: `idx_user_name`）
- 约束名: `pk_`(主键), `uk_`(唯一), `fk_`(外键)

#### 3.1.2 字段规范
- 主键: `id` BIGINT 自增
- 时间戳: `create_time`, `update_time`
- 状态字段: `enabled`, `status`
- 软删除: `deleted`

## 6. 安全设计

### 6.1 认证流程

```
OAuth2 授权码模式流程:

1. 用户访问客户端应用
2. 客户端重定向到授权服务器 /oauth2/authorize
3. 用户在授权服务器登录页面输入用户名密码
4. 授权服务器验证用户身份
5. 显示授权确认页面，用户确认授权范围
6. 授权服务器生成授权码并重定向回客户端
7. 客户端使用授权码请求访问令牌
8. 授权服务器验证授权码并返回访问令牌
9. 客户端使用访问令牌调用资源服务器API
10. 资源服务器验证令牌并返回数据
```

### 6.2 安全配置

#### 6.2.1 密码加密

```java
/**
 * 密码加密配置
 * 
 * 使用 BCrypt 算法加密用户密码
 * 强度因子: 10 (可调整)
 */
@Configuration
public class PasswordEncoderConfig {
    
    @Bean
    public PasswordEncoder passwordEncoder() {
        return new BCryptPasswordEncoder(10);
    }
}

/**
 * 安全配置类
 * 
 * 配置 Spring Security 安全策略：
 * 1. HTTP 安全配置
 * 2. CSRF 防护
 * 3. XSS 防护
 * 4. SQL 注入防护
 */
@Configuration
@EnableWebSecurity
@EnableMethodSecurity
public class SecurityConfig {
    
    @Bean
    public SecurityFilterChain securityFilterChain(HttpSecurity http) throws Exception {
        http
            .csrf(csrf -> csrf.ignoringRequestMatchers("/oauth2/token")) // OAuth2 端点忽略 CSRF
            .headers(headers -> headers
                .xssProtection(xss -> xss.headerValue(XXssProtectionHeaderWriter.HeaderValue.ENABLED_MODE_BLOCK))
                .contentSecurityPolicy(csp -> csp.policyDirectives("default-src 'self'"))
            )
            .authorizeHttpRequests(authz -> authz
                .requestMatchers("/login", "/oauth2/**").permitAll()
                .requestMatchers("/api/**").authenticated()
                .anyRequest().authenticated()
            )
            .formLogin(form -> form
                .loginPage("/login")
                .permitAll()
            )
            .oauth2ResourceServer(oauth2 -> oauth2
                .jwt(jwt -> jwt
                    .decoder(jwtDecoder())
                )
            );
        
        return http.build();
    }
}

### 10.3 监控指标

```java
/**
 * 自定义监控指标
 * 
 * 记录 OAuth2 相关操作指标
 */
@Component
public class OAuth2Metrics {
    
    private final Counter loginAttempts;
    private final Counter successfulLogins;
    private final Counter failedLogins;
    private final Timer tokenGenerationTime;
    
    public OAuth2Metrics(MeterRegistry registry) {
        this.loginAttempts = registry.counter("oauth2.login.attempts");
        this.successfulLogins = registry.counter("oauth2.login.success");
        this.failedLogins = registry.counter("oauth2.login.failed");
        this.tokenGenerationTime = registry.timer("oauth2.token.generation.time");
    }
    
    public void recordLoginAttempt() {
        loginAttempts.increment();
    }
    
    public void recordSuccessfulLogin() {
        successfulLogins.increment();
    }
    
    public void recordFailedLogin() {
        failedLogins.increment();
    }
    
    public void recordTokenGeneration(Runnable operation) {
        tokenGenerationTime.record(operation);
    }
}

### 12.2 常见问题

**Q: 如何添加新的 OAuth2 客户端？**
A: 在 `AuthorizationConfig.java` 的 `registeredClientRepository` 方法中添加新的 `RegisteredClient` 配置。

**Q: 如何自定义授权确认页面？**
A: 修改 `templates/consent.html` 模板文件，确保表单提交到 `/oauth2/consent` 端点。

**Q: 如何添加新的权限范围？**
A: 在客户端配置中添加新的 scope，并在资源服务器中实现相应的权限验证。

**Q: 生产环境如何配置 HTTPS？**
A: 配置 `application-prod.yml` 中的 SSL 设置，使用正式的 SSL 证书。
