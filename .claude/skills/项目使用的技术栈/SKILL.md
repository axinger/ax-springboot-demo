# 项目技术栈

## 核心框架
- Spring Boot 2.7.18
- Spring Cloud 2021.0.6
- Spring Cloud Alibaba 2021.0.6.2
- Java 21

## 数据访问
- MyBatis Plus 3.5.16
- Spring Data JPA
- Redis / Redisson
- MongoDB

## 消息队列
- Kafka
- RabbitMQ
- RocketMQ

## 工具库
- Hutool 5.8.42
- Guava 33.5.0
- Fastjson2 2.0.49
- Lombok 1.18.34

## 构建工具
- Maven 3.8+

## 开发规范
- 包名: `com.github.axinger`
- 模型: PO/Entity(数据库实体)、DTO(传输)、VO(视图)、BO(业务)
