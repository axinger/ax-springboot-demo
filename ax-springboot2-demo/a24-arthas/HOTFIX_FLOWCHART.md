# Arthas 热更新流程图

## 📊 完整操作流程

```
┌─────────────────────────────────────────────────────────────┐
│                    发现生产环境 Bug                           │
│              calculateOrderTotal 方法有问题                   │
└────────────────────┬────────────────────────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────────────────────────┐
│              第一步：启动应用并复现 Bug                        │
│                                                             │
│  1. 启动应用: start.bat                                     │
│  2. 调用接口测试:                                            │
│     curl POST /api/demo/order-total                         │
│     {"prices": null, "discount": 0.2}                       │
│  3. 观察到: NullPointerException ❌                          │
└────────────────────┬────────────────────────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────────────────────────┐
│              第二步：使用 Arthas 诊断问题                      │
│                                                             │
│  1. 连接 Arthas: http://127.0.0.1:8563                      │
│                                                             │
│  2. 反编译查看代码:                                          │
│     jad com.github.axinger.service.DemoService              │
│     calculateOrderTotal                                     │
│                                                             │
│  3. 观察异常信息:                                            │
│     watch ... calculateOrderTotal                           │
│     '{params, throwExp}' -e                                 │
│                                                             │
│  4. 查看调用栈:                                              │
│     stack ... calculateOrderTotal                           │
│                                                             │
│  5. 发现问题:                                                │
│     • prices.size() 在 null 时崩溃                          │
│     • total - discount 计算错误                             │
└────────────────────┬────────────────────────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────────────────────────┐
│              第三步：准备修复代码                              │
│                                                             │
│  1. 导出当前类文件:                                          │
│     jad ... DemoService > /tmp/DemoService.java             │
│                                                             │
│  2. 获取 ClassLoader Hash:                                  │
│     sc -d ... DemoService | grep classLoaderHash            │
│     得到: 1a2b3c4d                                          │
│                                                             │
│  3. 编辑修复代码:                                            │
│     • 添加空指针检查                                         │
│     • 修正折扣计算公式                                       │
│     • 添加参数验证                                           │
│                                                             │
│  4. 保存修改后的文件                                         │
└────────────────────┬────────────────────────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────────────────────────┐
│              第四步：编译和加载新代码                          │
│                                                             │
│  1. 在线编译:                                                │
│     mc -c 1a2b3c4d /tmp/DemoService.java -d /tmp           │
│                                                             │
│  2. 检查编译结果:                                            │
│     成功: /tmp/com/github/axinger/service/                  │
│           DemoService.class                                 │
│                                                             │
│  3. 加载新类定义:                                            │
│     retransform /tmp/.../DemoService.class                  │
│                                                             │
│  4. 看到成功提示:                                            │
│     retransform success, size: 1 ✅                         │
└────────────────────┬────────────────────────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────────────────────────┐
│              第五步：验证修复效果                              │
│                                                             │
│  1. 反编译验证代码已更新:                                    │
│     jad ... calculateOrderTotal                             │
│     看到修复后的代码 ✅                                      │
│                                                             │
│  2. 测试正常调用:                                            │
│     {"prices": [100, 200, 300], "discount": 0.2}           │
│     返回: 480.0 ✅ (正确)                                   │
│                                                             │
│  3. 测试 null 输入:                                          │
│     {"prices": null, "discount": 0.2}                       │
│     返回: 0.0 ✅ (不再崩溃)                                 │
│                                                             │
│  4. 测试空列表:                                              │
│     {"prices": [], "discount": 0.2}                         │
│     返回: 0.0 ✅                                            │
│                                                             │
│  5. 测试折扣范围:                                            │
│     {"prices": [100], "discount": 1.5}                      │
│     返回: 错误提示 ✅                                        │
│                                                             │
│  6. 查看日志输出:                                            │
│     看到 WARN 日志，说明空指针检查生效 ✅                     │
└────────────────────┬────────────────────────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────────────────────────┐
│              第六步：同步源代码                                │
│                                                             │
│  ⚠️ 重要：retransform 是临时的，重启后会丢失                  │
│                                                             │
│  1. 将修复后的代码同步到源代码                               │
│  2. 提交代码到版本控制系统                                   │
│  3. 安排正式部署                                             │
│  4. 记录本次热更新操作                                       │
└────────────────────┬────────────────────────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────────────────────────┐
│                      🎉 修复完成！                            │
│                                                             │
│  • Bug 已在线修复                                            │
│  • 服务未中断                                                │
│  • 用户无感知                                                │
│  • 总耗时: ~5 分钟                                           │
└─────────────────────────────────────────────────────────────┘
```

## 🔄 回滚流程

如果热更新后出现问题，可以快速回滚：

```
方案 1: 再次热更新
   │
   ▼
retransform 原始版本的 class 文件
   │
   ▼
立即恢复


方案 2: 重启应用
   │
   ▼
restart application
   │
   ▼
自动恢复原始代码


方案 3: 紧急回滚
   │
   ▼
停止应用
   │
   ▼
重新部署上一个稳定版本
```

## 📋 检查清单

在执行热更新前，确认以下事项：

```
□ 已在测试环境验证修复方案
□ 已备份原始代码
□ 已通知相关人员
□ 选择在低峰期操作
□ 准备好回滚方案
□ 了解热更新的限制
□ 计划同步源代码
□ 记录操作步骤
```

## 💡 最佳实践

```
1. 先诊断，再修复
   ├─ 充分理解问题
   ├─ 定位根本原因
   └─ 设计修复方案

2. 小步快跑
   ├─ 每次只修改一个方法
   ├─ 避免大规模改动
   └─ 逐步验证效果

3. 及时同步
   ├─ 热更新后立即修改源代码
   ├─ 提交到版本控制
   └─ 安排正式部署

4. 详细记录
   ├─ 记录操作步骤
   ├─ 记录修改内容
   └─ 记录验证结果

5. 团队协作
   ├─ 通知团队成员
   ├─ Code Review 修复方案
   └─ 分享经验教训
```
